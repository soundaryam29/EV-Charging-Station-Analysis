# ⚡ EV Charging Station Analysis in India

### Analysis of Electric Vehicle Charging Infrastructure Using IBM Cognos Analytics

## 📌 Project Overview

Electric Vehicles (EVs) are becoming increasingly popular in India. The availability and distribution of charging stations play an important role in supporting EV adoption.

This project analyzes a sample dataset of EV charging stations in India using IBM Cognos Analytics. Different visualizations are used to explore station locations, state-wise distribution, and charging infrastructure.

## 🎯 Problem Statement

The growing adoption of electric vehicles increases the demand for accessible charging infrastructure. Analyzing charging station locations and their distribution can help understand the current sample data and identify areas for further investigation.

## 🎯 Objectives

- Analyze EV charging station distribution across states and cities.
- Visualize charging station locations.
- Explore charging station categories.
- Create interactive dashboards using IBM Cognos Analytics.
- Present data through different visualization techniques.

## 🛠️ Tools & Technologies

- IBM Cognos Analytics
- Data Visualization
- Microsoft Excel / CSV
- GitHub

## 📊 Dataset Description

**Dataset Name:** EV Charging Stations in India Dataset

The project uses a sample dataset containing 20 records and 7 fields.

| Column | Description |
|---|---|
| name | Charging station name |
| state | State where the station is located |
| city | City of the station |
| address | Station address |
| latitude | Geographic latitude |
| longitude | Geographic longitude |
| type | Station type information |

**Note:** This is a sample dataset used for academic analysis, not a complete official inventory of all EV charging stations in India.

## 📈 Dashboard Visualizations

The dashboard contains the following visualizations:

1. **Packed Bubble Chart** – Represents charging station distribution using bubbles.
2. **Box Plot** – Displays the distribution of the station count field.
3. **Heat Map** – Highlights patterns across selected categories.
4. **Legacy Map** – Displays geographical station information.
5. **Scatter Plot** – Explores relationships between selected data fields.
6. **Treemap** – Shows hierarchical distribution of station records.
7. **Column Chart** – Compares station counts across categories.
8. **Bar Chart** – Displays category-wise station distribution.
9. **Geographical Map** – Visualizes station locations using geographical coordinates.

## 🔍 Analysis & Limitations

- The sample data helps explore charging station locations and distribution.
- Geographic coordinates support map-based visualization.
- The dataset contains only 20 records, so results should not be treated as national-level statistics.
- The Box Plot has limited statistical value because the calculated Station Count is 1 for each record.
- Any AC/DC charger classification inferred from station names is not independently verified.

## ✅ Conclusion

This project demonstrates how IBM Cognos Analytics can be used to analyze and visualize EV charging station data.

The dashboard provides different views of the sample dataset through charts, maps, and graphical representations. It also demonstrates the importance of data visualization in understanding electric vehicle charging infrastructure.
